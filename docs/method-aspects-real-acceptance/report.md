## 失败层与最小替代设计

BPR B 的原文、符号类型、步骤参与者和索引动机都已在实际输入中。失败发生在模型从结构化事实写到用户正文时，结尾放弃了已经明确的对象绑定。对象复用 B 另暴露了机械校验把事实状态差异当成类型冲突的问题。

最小替代设计是先交付一条带来源的步骤记录，显式绑定操作、参与者、对象类型及返回范围。只允许将未知挂到未确认的具体属性。直接显示已核验的步骤记录，将通俗解释作为附加字段。若解释否定或重新悬置了已确认绑定，则拒绝交付并保留原答。类型冲突比较作用域内的类型值，证据状态另行保存。参与者字段只在运算分支的结构中提供。

可先用本轮两份 B 原答作为失败回放，再用一篇独立论文检验相同对象的跨步骤复用。沿用同一模型和原有科学判据。这个设计适用于明示对象与运算的步骤，仍需人工核查动机和因果解释。本轮未实施。
