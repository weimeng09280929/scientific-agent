# 九道开发题与首轮判据

PDF 页码从 1 开始。问题原话见本轮实际输入。每题记录主要要点、入模证据、关键错误、保存与首段表达。用户未问到的额外细节可以省略。含错误的额外断言仍需记载。

| 题 | 必答要点 | 可独立核对的原文与关键错误 |
| --- | --- | --- |
| B1 · BPR 两阶段 | 汉明距离粗筛用问题二值码与段落二值码，从整个索引取前 l 个。重排用连续查询与同一个段落二值码内积，只从候选取前 k 个。 | BPR p.3 §3.3。把段落码写成连续嵌入、把重排当作对全库搜索、把原文明确符号降成未知均失败。 |
| B1f · 重排追问 | 简洁确认重排双方的表示和返回范围。段落端保持二值码，索引存储更紧凑。作者给出的设计取舍与未实测的因果解释分开。 | BPR p.2 二值索引与内存动机、p.3 §3.3。不得用「还没看代码」否定论文描述。内存精确数值非必答。 |
| S1、S2 · SimCSE | 两种说法均核对无监督正对来自同一句的两次前向及独立 dropout，负例来自同批其他句子。与有监督 NLI 的蕴含正例、矛盾难负例区分。 | SimCSE p.2 图 1 和 p.3 §3。把无监督设定混成 NLI 或说 dropout 改写原句均失败。 |
| T1、T2 · 两阶段继续训练 | 已有 RoBERTa，先用大规模目标领域未标注文本做 DAPT，再用目标任务直接相关的未标注训练文本做 TAPT。区分有监督分类微调。 | Gururangan 等 p.2 §3、p.5 §4、p.6 组合段。两批文本混用、说任一步使用任务标签，或只能说明第一阶段均失败。 |
| D1 · DPR 分母 | 按题计，分子为前 k 中至少有一段包含答案跨度的题数，分母为总题数，指标为比例或百分数。表注的字面分母与正文有歧义，可查实现。 | DPR p.2 §2、p.5 表 2 表注。单个比率的单位写成百分点，或宣称表注证明了两套实现均失败。 |
| D2 · DPR 表 2 | Top-20，NQ 为 Single DPR 78.4 对 BM25 59.1，SQuAD 为 63.2 对 68.8，差距方向相反。锁定同列及正确训练行。 | DPR p.5 表 2 和 §5.1。百分点若展示必须为 +19.3、−5.6。用户问原数与方向，原数和方向正确且清楚拒算时单列拒算，不因此改变科学结论。 |
| B2 · BPR 表 1 | 同一数据集和 k 下，线性扫描 l=1000 对 DPR，NQ/TQA Top-1 的差为 −4.9、−3.8，Top-20 的差为 −0.5、−1.5 个百分点。解释重要性与差距成因的区别。 | BPR p.4 表 1、§4.1。程序核算须在网页出现，正文与核算一致。 |

表达评分单独记录。首段答到主要问题且无需先读背景为「清楚」，先兜圈或关键答案藏在后段为「不清楚」。只有 12/12 科学判据通过且至少 10/12 首段清楚才进入主线。
