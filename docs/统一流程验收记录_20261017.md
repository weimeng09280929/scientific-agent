# 统一流程验收记录

范围：本地代码与隔离服务，不训练模型，不运行指定项目实验，不调用真实付费模型，不推送 GitHub，不替换用户数据。

## 已实现

- 服务端统一主线、阶段与继续动作；保留后台节点作为材料执行器。
- 问题与方案的服务端选择；浏览器清空本地记忆后仍可恢复。
- 既有思路、研究缺口、方法、实验任务与结果的明确关联，保存来源编号和指纹。
- 同一来源幂等关联，跨项目/跨问题/跨任务限制，空正文与无指标旧结果的边界校验。
- 关联任务的手动结果登记与旧实体在同一 SQLite 事务中更新；修订保留历史，不新增记录偷偷覆盖。
- 来源变更导致下游待复核；继续入口定位结果复核而非重复新建。
- 总览、顶部科研路径、指导上下文与继续入口使用同一 workflow；关联任务与结果不再重复相加为实验数量。
- 导出综合报告包含当前研究主线；演示和预期标记保留。
- Web 与 Pipeline 都禁止真实模式 force_writing 绕过结果审核；写作骨架仍可提前整理。
