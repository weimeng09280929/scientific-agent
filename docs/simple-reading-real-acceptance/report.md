三模型每题使用相同问题、原文、证据编号、指令、`DirectPaperWireDraft` 和生成参数。逐字节核对实际发送与本轮冻结请求一致。同一题的三份载荷只更换 `model`。Chat Completions 的温度为 **0.2**，输出预算为 **8192** token。BPR 两题固定使用第 1 页末、第 2 页首和第 3 页 §3.3，BERT 使用第 4 页两段原文。选段在发送前与已入库公开 PDF 文本核对。盲审时只展示匿名原答及实际原文，保存人工评分后揭盲。 [匿名原答及材料](blind-review.json) · [揭盲前评分](manual-blind-scores.json) · [完整原答、终态、引文快照和揭盲映射](screening-index.json)

旧 BPR B 的 c7 增加了不必追问的连续段落表示疑问，c8 把已有索引存储动机降为缺项。旧对象复用 B 的 `binary/explicit` 和 `binary/inference` 类型值相同。非运算项携带 `participant_ids` 属于契约遵循和交付问题。旧回答、判定和账本原样保留。本轮同时改了输出契约和指令，筛选题也有变化。旧复杂契约结果与新结果不能直接用于归因或估计准确率改善。 [旧验收报告](../method-aspects-real-acceptance/report.md) · [旧逐次结果](../method-aspects-real-acceptance/fixed-index.json)

本轮 [生成入口](../../core/workspace/guide.py) 增加默认关闭的 `simple-reading-v1`。精简正文只接受 `reply`、`cited_paper_ids` 和 `reading_citations`。固定筛选实际复用了生成入口、输入额度和严格 JSON 校验。隔离网页的 focused reading 路由留给通过筛选的模型，表格保留原契约和计算分支。普通讨论、方案生成和日常模型配置沿用现有入口。隔离网页路由及业务保存本轮未执行。
