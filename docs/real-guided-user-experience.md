## 本轮如何操作

使用真实主应用 `index.html`、实际 FastAPI 和 SQLite，没有替换模型回复、主要业务接口或来源返回。
新项目通过正常 `/api/conversations/start` 创建，随后逐轮使用实际聊天、步骤选择、论文参考选择、
问题采纳、方案生成、方案采纳、下载及重试界面。项目 brief 通过正式接口保存模拟用户已明确声明的条件。
不将这种验收脚本操作描述为未经辅助的新手已经认可体验。

模拟用户条件：第一次做科研；Python 会课程作业和简单脚本，没有深度学习项目经验；
线性代数和概率有基础；四周、普通笔记本 CPU、无 GPU；只制定研究方案，不执行实验。
这些条件只属于本验收项目，不是实际用户的个人背景。

| 轮次 | 用户实际表达与操作 | 实际得到的内容 |
| --- | --- | --- |

| 3 | 明确授权围绕 FedAvg/FedProx 与 non-IID 检索 | 3 条查询 × OpenAlex/arXiv 两来源，真实入库 20 篇，保存研究现状报告 v1 |
| 4 | 在材料面板选择 FedProx、FedBN、FedNova，追问怎样读摘要 | 比较三种问题设定，说明能支持什么、不能外推什么，未冒称读过全文 |
| 5 | 进入研究现状与 gap，要求区分已有工作和未核实事项 | 得到两个待研究切口；“尚未核实”与“领域无人做过”分开 |

| 8 | 审阅后提出主指标、范围、因果归因边界等修订意见 | 网关连接失败；明确重试一次后仍失败，原方案及原用户消息保留，没有第二版 |

## 模型、耗时与费用

实际模型：`deepseek-v4.1-flash-1017`，经当前配置的真实网关；没有使用离线夹具、规则回退或手工回答。

- 本轮预先限制：最多 16 次实际模型网络尝试、6 次学术来源请求，包含重试。
- 实际：16 次模型网络尝试，其中 9 次成功、7 次 `APIConnectionError`；来源请求 6 次。
- 9 次成功返回已知输入 token 73,899、输出 token 36,433，其中 reasoning token 20,953。
- 7 次连接失败没有返回 usage；它们是未知，不计成零 token 或免费。
- 普通有效指导轮次约 19–23 秒（含本地准备）；候选筛选 HTTP 约 50 秒、研究现状综合约 57 秒；
  检索到报告的整项任务约 148 秒；初版方案请求约 52 秒。
- 两轮真实回答各出现过一个无效采纳操作：操作独立拒绝、记录提示，正文仍交付，审计共记录 2 次操作拒绝。
- 修订首次失败的四次网络尝试与明确重试的三次尝试均记录；达到 16 次后没有继续扩量，预算闸门在发送前检查。
- 另外做了 1 次只读模型目录连通性检查，也发生连接错误；它不是模型推理或文献检索，没有冒充成功。
- 网关费率与账单未取得，费用仍为未知。没有把历史账户额度确认当成本轮费用的独立证明。
