# 固定材料对照判据

每个问题各用 A 和 B 执行一次，计划六次。两组同用 Flash、同题、同一组原文及编号、相同温度和输出预算。A 使用 `MethodReadingDraft`，B 使用 `AspectReadingDraft`。两组都使用修正后的声明提取。B 增加契约必需的对象目录及其边界说明。完整系统指令差异、原文一致性断言、各请求体和哈希见 [对照清单](comparison.json)。

这是人工固定充分材料的诊断。BPR 为已知开发题，另外两项是分别编写的合成开发材料。由人工按下面的预先固定判据核对原文和原答。模型自评和机械校验结果分别记录。该包的结果不进入网页自动选段通过率。

每个回答分别检查事实正确性、必答要点、正文与结构化事实一致性、缺失范围、引用支持、拦截及可见错误。关键错误即判科学失败，即使被校验拦截也保留原答。提供商响应成功、机械校验通过和人工科学通过分别记录。首轮和第二轮历史结果仍按各自原口径。
