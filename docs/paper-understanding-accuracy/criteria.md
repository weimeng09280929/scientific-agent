# 论文理解判据与问题

开发样本使用两篇 ACL Anthology 公开论文。下文是人工判据。实测时只给模型用户问题和选入的原文；作者实现用于独立核对，网页模型不可据此声称已经阅读代码。页码从 PDF 第一页开始计。

| 编号与实际问题 | 最小原文及通过条件 |
| --- | --- |
| D1 · 只看这篇论文。第 2 节的 top-k retrieval accuracy 按什么单位计？说清分子和分母。表 2 的表注如果读起来像另一种口径，该怎样核对？ | DPR p.2 §2 的定义，p.5 表 2 表注。一次评价一题，分子是其前 k 候选中至少有一段含答案 span 的题数，分母是参与评价的总题数。表注字面按段落理解会有歧义，不能由措辞推断用了两个实现；回查代码的首命中累加和归一化。只见表注时应说明缺定义或实现。 |
| D2 · 只看这篇论文。表 2 的 Top-20，单数据集训练 DPR 和 BM25 在 NQ、SQuAD 上各是多少？这两个数据集的差距方向相同吗？ | DPR p.5 表 2 双层表头与完整对应行，§5.1 例外。NQ 78.4 对 59.1，DPR 高 19.3 个百分点。SQuAD 63.2 对 68.8，DPR 低 5.6 个百分点。不可混入联合训练、混合检索或 Top-100。缺任一列时不补数。 |
| B1 · 只看这篇论文。它怎样先筛候选、再重排？每一步的查询和段落分别用什么表示，最后返回什么？ | BPR p.3 §3.3，必要时回看 §3.2 的符号与 p.2 图 1。先用二值查询与二值段落码的汉明距离取前 l 个候选；再以连续查询向量和候选段落二值码的内积重排，返回前 k 个。不可说两侧都变连续或无依据更正符号。 |
| B1f · 重排呢？为什么段落用这种表示？ | 与 B1 相同论文和 §3.3，加 p.2 或 p.3 关于二值索引的动机。查询侧连续以表达更丰富的打分信息，段落侧保留二值索引可减小存储。动机与实测分开，不能推出每个设置都准确率不变。不给出上一轮助手答案作为证据。 |
| B2 · 只看这篇论文。表 1 中线性扫描的 BPR 对比 DPR，在 NQ、TQA 的 Top-1 和 Top-20 有什么差异？作者关于小 k 的解释能说明差距的成因吗？ | BPR p.4 表 1 表头、DPR 和线性扫描两行及 §4.1。NQ 的 Top-1 为 41.1 对 46.0，Top-20 为 77.9 对 78.4；TQA 为 49.7 对 53.5、77.9 对 79.4。对齐 BPR 在前。小 k 影响对下游相对次要的解释不确立掉点成因。不得推及所有 k，也不得从索引变小直接归因。 |

## 作者代码核对

- DPR 固定提交 `a31212dc0a54dfa85d8bfa01e1669f149ac832b7`。匹配函数为每题找到第一个命中的段落，再为覆盖该排名的各个 k 累加一次；检索器的验证函数按结果题数归一化。代码支持 §2 的题级含义。 [首命中累加](https://github.com/facebookresearch/DPR/blob/a31212dc0a54dfa85d8bfa01e1669f149ac832b7/dpr/data/qa_validation.py#L67-L82) · [归一化](https://github.com/facebookresearch/DPR/blob/a31212dc0a54dfa85d8bfa01e1669f149ac832b7/dense_retriever.py#L307-L315)
- BPR 固定提交 `08b70cf4806758223b73b7553df8eeeb5745c8df`。二值索引先取候选，随后将段落位向量解包并映射至 ±1，与查询浮点向量做内积；用浮点类型存放 ±1 并不恢复连续段落嵌入。评估器在第一段含答案时按 k 累加，除以样本数。公开版本与论文叙述交叉核对，未据此宣称复现了表中实验。 [重排实现](https://github.com/studio-ousia/bpr/blob/08b70cf4806758223b73b7553df8eeeb5745c8df/bpr/index.py#L85-L119) · [评估实现](https://github.com/studio-ousia/bpr/blob/08b70cf4806758223b73b7553df8eeeb5745c8df/evaluate_retriever.py#L182-L198) · [文件哈希](author-source-versions.json)

## 评分与隔离

科学结论准确性、证据是否充分、引文可定位、回答易懂程度分别记录。正确承认材料不足只计证据边界通过。网页实际选段记为 A，人工核对最小证据的同题对照记为 B。B 的回答不会计入网站通过率。比较均采用当前授权模型。语义评阅按上述人工判据对照 PDF 和源码。保留样本在产品版本冻结后才按 PDF 设题并发起。
