## 环境与费用控制预检

- 项目解释器为 `venv/Scripts/python.exe`，Python 3.13.14，pypdf 6.21.4 实际来自项目 `venv/Lib/site-packages`。启动脚本仍将 8001 和 8077 指向项目 venv。阶段 A 核对时 8001、8002、8077 未监听，未启动或关闭这些服务。
- 旧 `tools/serve_guided_experience.py` 只对固定项目加次数，其他项目仍可走普通调用，且无金额、时效和全局账本。本轮复用 `ExperienceBudget` 和既有调用审计。验收入口须显式填写本轮批准的模型、单价、累计金额、次数、绝对截止时间及输入输出上限。使用日常配置加载器，将日常任务路由原样复制到隔离目录；校验所有路由使用指定模型，并锁定实际 TokenDance 请求端点。原配置和旧体验授权留在原处。
- 每笔费用在 HTTP 发送前原子预留。同一个隔离进程的所有账号、项目、对话和请求 ID 共用同一个持久账本；重启、换账号或改请求 ID 不增加余额。请求体上限 **160,000 个 UTF-8 JSON 字节**，单次 `max_tokens` 上限 **12,000**。预留额 =（实际序列化请求字节数 + 4096）× 2 / 1,000,000 + `max_tokens` × 8 / 1,000,000 元。字节是保守预算代理，不是 tokenizer 实测。允许应用在低于金额上限时因下一次预留不足而停止。¥5 是本地预留上限，实际结算以 TokenDance 账单为准。
- 仅正常会话发送及明确重试可以产生一次模型网络尝试。伴读和翻译走同一发送入口，异步方法草案继承发起操作。连接与结构错误不自动补发；后台检索、流水线和新恢复轮次在入口禁用。已有 PDF 用本地 pypdf，外部下载、联网文献源与外部解析禁用。未识别的端点、其他模型、超限请求、工具调用和多模态请求在网络前拒绝。

- 实测使用真实 FastAPI、实际 OpenAI 兼容 SDK 和 MockTransport，核对日常配置加载、TokenDance 请求端点、模型、过期启动拦截，以及普通发送、伴读、选段、异步草案和明确重试共享额度。两个账号跨项目用完后，换请求 ID 仍无法出网。另验证金额、价格变更、币种、跨端点以及重启重新打开账本。Windows 上首次运行受默认临时目录权限限制，改用仓库内长路径时又遇到会话锁路径限制，最终使用短系统临时路径复跑 **21 项通过**，无跳过。测试只验证离线拦截与状态。[预算与路由预检 JUnit](real-user-acceptance/stage-a-budget.xml)

### 问题记录
