## 当前界面实查

使用实际主应用检查无项目首页、项目工作区、已有对话、研究摘要、右上角菜单与材料面板；查看桌面和 390px 窄屏。浏览器中使用的是本轮临时测试项目，不是用户历史项目，模型回复来自离线替身，不评判其科学内容质量。

1. 无项目首页仍同时呈现“科研对话”“开始新研究”“新对话”“新研究·首次发送后建立项目”等重复层级。首次用户需理解过多界面术语。
2. 研究摘要在对话上方展开，占用对话空间；其问题、条件和下一步与材料面板有重复。
3. 三点菜单展开后点击输入框仍保持打开；Esc 能关闭。应补齐外部点击关闭和焦点返回，不应把 Esc 已有效的行为列为待修 bug。
4. 材料面板同时呈现当前问题、当前方案、论文、报告、已有材料、待采纳草案和其他页面；无材料时仍占据多个说明段落。建议统一分类及空态，保留当前/草案/历史的区分。
5. 当前样本的近期对话多为同类标题“梳理文献与现状”。样本来自测试输入，不能据此断言真实项目命名全都不合理；下一批应用有意义的研究主题做长名、重名辨识验收。
