## 论文与判定基准

使用先前从 ACL Anthology 保存的两份公开出版 PDF，存于 `.pytest_cache/real-user-acceptance-stage5/inputs`。本轮已复核文件指纹、页数和 pypdf 页内关键字。参考核对表沿用人工对照视觉版表格与页内原文的记录，页码以 PDF 首页为第 1 页。表格双栏、连字和公式的提取顺序可能异于视觉版。[详细人工核对表](../../real-user-acceptance.md#两篇论文及独立原文核对表) · [本轮 PDF 指纹和逐页文字](environment.json)

| 材料 | 核对重点 |
| --- | --- |
| DPR，Karpukhin 等，2020，DOI `10.18653/v1/2020.emnlp-main.550`，13 页均有文字层。 | PDF 第 2–3 页，段落和问题分别编码，用内积找候选段落，后续答案由独立阅读器给出。第 5 页 §5.1 与表 2，NQ Top-20 单数据训练 DPR 为 78.4%，BM25 为 59.1%。SQuAD 分别是 63.2% 与 68.8%。词汇重叠和文章集中是作者的可能解释。[出版记录](https://aclanthology.org/2020.emnlp-main.550/) · [原 PDF](https://aclanthology.org/2020.emnlp-main.550.pdf) |
| BPR，Yamada、Asai、Hajishirzi，2021，DOI `10.18653/v1/2021.acl-short.123`，8 页均有文字层。 | PDF 第 3 页，先用二进制码的汉明距离找候选，再用问题连续向量与段落二进制码的内积重排。第 4 页 §4.1 与表 1，线性 DPR/BPR 的 Top-1 在 NQ 为 46.0%／41.1%，在 TQA 为 53.5%／49.7%。Top-20 在 NQ 为 78.4%／77.9%，在 TQA 为 79.4%／77.9%。索引为 64.6 GB／2.0 GB，哈希表 BPR 为 2.2 GB。以视觉版核对 `k = 1` 的条件和劣化方向。[出版记录](https://aclanthology.org/2021.acl-short.123/) · [原 PDF](https://aclanthology.org/2021.acl-short.123.pdf) |

这些证据限于文中语料、基准、方法及实验设置。检索命中、最终答对率、索引文件大小、整机内存各有不同含义。无法据此证明中文科研 PDF 的表现、其他机器的延迟、全面不劣或选题的创新性。某次请求实际没有提供表格或正文时，合格答复应说明缺少什么。测试只在真实页面提交下列输入，表中的核对数值和结论供验收人员对照。

## 主线和费用操作

每行最多 1 次网络尝试，总计 **12 次计划操作**。另保留最多 **4 次**给明确必要的定向复测。未取得满足条件的合格候选或草案时停止相应下游动作。普通对话上下文采用最多 42,000 字符的应用预算。选段最多 1,000 字符，同段相邻文本各最多 160 字符。所有发往网关的请求另设 104,000 字节硬上限，字符数、字节数和网关 token 各自记录。
